# A signal in woodland restoration

In six South Australian woodland plots, both the Acoustic Complexity Index and the Bioacoustic Index correlated with animal abundance. Only the complexity index showed a statistically significant association with the number of distinct invertebrate types.

**Evidence.** Peer-reviewed field evidence.

**Limit.** The hand-sort distinguished some organisms only at broad taxonomic ranks and separated some unnamed forms within groups. This five-day field comparison did not test commercial SAQI.
