# Sounds of the underground, data and analysis code, version 1 (2024)

The authors’ dataset contains acoustic-index tables, invertebrate counts, field metadata and R analysis code from Mount Bold, South Australia.

**Interpretation.** Inverts_Ordination.csv distinguishes several numbered ant, spider and larval types alongside broader groups and a named earthworm species. Richness measures the different types distinguished in the hand-sort. The file is not a species-identification library.
