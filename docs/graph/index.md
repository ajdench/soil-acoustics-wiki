# Knowledge graph

Use the graph to find the records behind a topic. For example, search for `Denton` to find the case about baseline recordings at a Yorkshire reserve. Each point represents an item from the wiki. Each line represents a relationship extracted from the underlying files.

Choose [2D](two-dimensional.md) to inspect an item and its neighbours, or [3D](three-dimensional.md) to explore the same records in three dimensions. Both views include a text summary and a link to the complete dataset.

To check a conclusion, read the claim and its limit in the [evidence matrix](../evidence-matrix.md), then follow its citation to the [source register](../sources.md). The number of lines attached to a point describes its connections in the wiki.
