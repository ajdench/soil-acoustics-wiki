# Validation queue

These three questions affect how a land manager can use the meter or compare it with another service. Each is parked until the evidence described below becomes available. The dates show when the review last checked each gap.

## How much must the commercial score change to be meaningful?

A repeatability study would show how much the Soil Acoustic Quality Index (SAQI) varies when measurements are repeated under comparable conditions. The Newhouse Farm operator describes using the meter. A conference programme lists the pilot presentation. At Denton Reserve, the developer reported differences *between* sites. None of those results measures variation from repeated recordings at the same point. The [Finnish forest project](company-and-product.md#what-has-been-tested) describes a planned comparison with soil animals. [SRC-010](sources.md#src-010), [SRC-051](sources.md#src-051), [SRC-053](sources.md#src-053), [SRC-054](sources.md#src-054)
